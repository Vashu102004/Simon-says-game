#  Simon Says Game

A classic digital recreation of the popular memory game "Simon Says" built using **HTML, CSS, and JavaScript**. Test your memory by repeating the sequence of colors

##  How to Play
1. **Start:** Press any key on your keyboard to start the game.
2. **Watch:** The game will flash a specific sequence of colors.
3. **Repeat:** Click the colors in the exact same order that Simon showed you.
4. **Progress:** Each round, the game adds one more color to the sequence.
5. **Game Over:** If you click the wrong color, the game ends. Your screen will flash red, and your score will be displayed.
6. **Restart:** Press any key to start a new game and try to beat your highest score!

##  Features
- **Interactive UI**: Engaging and colorful buttons that flash when active.
- **Dynamic Scoring**: Keeps track of your current score (level).
- **Responsive Design**: Playable on both desktop and mobile devices.
- **Visual Feedback**: Smooth flash animations when buttons are pressed by the user or the game.

##  Technologies Used
- **HTML5**: For structuring the game interface.
- **CSS3**: For styling, animations, and responsive design.
- **JavaScript (Vanilla)**: For game logic, sequence generation, event handling, and DOM manipulation.
